# Comandos de Dominio — rust-plc-modbus-agent-skill

- `$rustplc`: Bootstrap e inyección de la habilidad Modbus PLC en Rust.
- `$rustplc:audit`: Auditoría de conectividad Ethernet, runtime Tokio y registros mapeados del PLC. Registra hallazgos en `overview/work/skill/rust-plc-modbus.md`.
- `$rustplc:read [ip] [port] [reg]`: Genera snippet de lectura asíncrona de registros.
- `$rustplc:task`: Genera la estructura de un worker loop asíncrono con `tokio::spawn`.
